# E-Commerce_Sales_Dashboard
E-Commerce Sales Dashboard using Microsoft Excel

Project Objective :  It provides insights into sales performance, customer behavior, and product trends using dynamic visualizations and data analysis techniques.
Analyze overall sales performance, Enable data-driven decision-making.

Tools & Technologies : 
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers & Timelines
- Data Cleaning & Transformation
- Conditional Formatting

Insights :

-Highest Revenue Region
-Profit MArgins across different age category
-Order Channels Comparison
-Gender Sales Comparison
-Order Status
